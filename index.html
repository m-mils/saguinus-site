Saguinus

A clean, document-shaped markdown editor.

Write markdown the way it's meant to feel — a continuous page with no interrupting breaks, page guides that show where your document will split on export, live formatting as you type, and a plain-text file underneath that stays clean no matter how much you copy, paste, and edit.

Download for Windows

Windows

Free to use during live testing — donations are welcome if you find it useful.

Page guides, not page breaks

Write in one continuous flow with no interruptions — subtle page guides show exactly where pages will fall, so what you see lines up with what you get when you export to PDF.

Live rich rendering

Headings, bold, italics, strikethrough, links, and images render as you type, while the file underneath stays plain markdown.

Math with KaTeX

Write inline and block math using familiar LaTeX syntax, with editable source and dedicated toolbar buttons.

Tables & task lists

Build tables and checkbox task lists that render cleanly and round-trip back to markdown without losing structure.

Code blocks

Syntax-highlighted code blocks for sharing snippets, configs, and examples alongside your writing.

Built-in markdown guide

A quick-reference "Markdown Guide" panel covers every supported construct, right inside the app — handy for newcomers.
