Installing Saguinus on Linux

There are two ways to get Saguinus on Linux: a .deb package (recommended on Debian/Ubuntu-based distros — Ubuntu, Mint, Pop!_OS, etc.) or a portable .AppImage (works on any distro, no installation).

Option 1: .deb (recommended on Debian/Ubuntu-based distros)

  • Download Saguinus-X.Y.Z.deb from the Releases page.
  • Install it: 
    sudo dpkg -i Saguinus-X.Y.Z.deb
    Many file managers can also install a .deb directly if you double-click it instead — this varies by distro/desktop environment.
  • Saguinus now appears in your application menu with its icon, and .md files can be opened with it via right-click → Open With.
  • To update: download the new .deb and run the same dpkg -i command again — it replaces the installed version in place.

Option 2: AppImage (any distro, no installation)

  • Download Saguinus-X.Y.Z.AppImage from the Releases page.
  • Make it executable: 
    chmod +x Saguinus-X.Y.Z.AppImage
    (or right-click → Properties → Permissions → "Allow executing as program", on most file managers)
  • Double-click it, or run it from a terminal, to launch. Nothing is installed system-wide — it's a single self-contained file.

Note: a bare AppImage doesn't add an icon, app-menu entry, or "Open With" registration on its own — that's normal AppImage behavior on every distro, not a Saguinus-specific limitation. If you want those, use the .deb instead.

A note on updates

Saguinus doesn't yet check for or install updates automatically on Linux (it does on Windows). If a new version is available, the app will show a notice linking back here — check the Releases page and reinstall using the steps above.
