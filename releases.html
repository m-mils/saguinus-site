Known issues

Saguinus is still in live testing, so a few rough edges remain. Here is what's currently known and being worked on:

  • Inline and block math don't yet show a visual highlight while you're editing them — the math itself renders correctly, but it can be hard to tell exactly where your cursor is inside the formula.
  • Inserting a code block while text is selected replaces the selection instead of moving it into the new code block — select your text first, then re-add it to the code block manually after inserting it.
